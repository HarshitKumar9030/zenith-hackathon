# Repository instructions

- This repository contains WasteWise (initially named Relay) for the Zenith hackathon.
- Keep application code in `web-app/`, optional model work in `model/`, and documentation in `docs/`.
- Keep documentation current as implementation and setup change.
- Commit completed work regularly with descriptive commit messages.
- Never include more than 6 changed files in a single commit. Split larger changes into coherent commits.
- Keep secrets, dependencies, generated builds, local datasets, and model weights out of Git.
